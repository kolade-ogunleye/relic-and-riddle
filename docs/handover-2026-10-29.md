## 5. How to work here (binding)

- **Development** is this checkout; **production** is `content-client-win-01.lab.internal` (app
  `C:\Users\omokolade.LAB\relic-and-riddle`). Never deploy development's `.env`, database, counters, approvals or
  queue. Never read or print `.env` values. Production writes need the operator's explicit go-ahead.
- **Production SSH** (read-only use), one session at a time, always with timeout:
  `timeout 110 ssh -o BatchMode=yes -o ConnectTimeout=40 -o UserKnownHostsFile=~/.ssh/known_hosts_lab -J 10.10.20.20 -l 'LAB\omokolade' content-client-win-01.lab.internal '<PowerShell 5; use ; not &&>'`.
  Run Python there by piping a local script into `.venv\Scripts\python.exe -`; SQLite read-only (`?mode=ro`).
- **Releases:**
  - Before signing, run the full suite in two fresh worktrees: dev mode
    (`.venv/Scripts/python.exe -m pytest -q -n 4 -p no:cacheprovider`) and deployer mode (`env -u
    RELIC_ENVIRONMENT PATH=".../ffmpeg-8.1-full_build/bin:/c/Windows/System32" PYTHONDONTWRITEBYTECODE=1 ...`).
  - Sign only with the operator's go-ahead for that release:
    `KEY="$(timeout 20 ssh-add -L|head -1)"; git -c gpg.format=ssh -c gpg.ssh.program=C:/Windows/System32/OpenSSH/ssh-keygen.exe -c user.signingkey="key::$KEY" tag -s v1.0.0-rcN -m "v1.0.0-rcN" <commit>`.
  - Verify with `allowedSignersFile=deployment/windows/release/allowed_signers`, then push the branch and the tag.
  - The signing card sits in the laptop's **Alcorlink** reader (not a YubiKey). If signing is refused or the card
    reads "No such device", reset from PowerShell:
    `Get-Process | ? Name -match 'gpg|scdaemon|keyboxd|pinentry|^ssh$|ssh-keygen' | Stop-Process -Force; gpgconf --kill all; gpgconf --launch gpg-agent; gpg-connect-agent "scd serialno" /bye`.
- **Quality standard (operator, binding, the reason this project exists):** the operator's bar is an "elite 10/10,
  the highest quality ceiling where there is no more room for quality gain"; nothing is left untouched, including
  fonts, formatting and spacing, in the video, every graphic, the covers, Stories, carousels, captions AND the
  Telegram UI. In practice:
  - **Never settle.** Cycle build, measure, independent critique, fix until a further round gives no gain; say
    plainly what still keeps a surface from 10 and what it would take. A critic stopping early because gains got
    small is not acceptable.
  - **Measure, don't assert.** Contrast at least 4.5:1 on the delivered pixels (ring method, `typography`); every
    text inside `src/safe_zones.py`; colour casts, saturation and hue measured across many topics (not one);
    motion measured; timings measured. Evidence renders and measurements ship with every quality step in
    `docs/reviews/<step>-<date>/` (README + measurements + half-size before/after JPEGs).
  - **Verify before claiming.** Audit every live run's cards against `output/<run>/` and the logs before the
    operator looks; a claim in a card that the data does not back is a defect. Check the operator's screenshots
    critically (a vertical bar that reads as "I" is a defect).
  - **Root causes, not patches;** separate true positives from false positives in every check; topic-agnostic code
    only (`tests/test_no_topic_hardcoding.py`); facts only from the verified fact sheet (disputed figures as floors,
    single estimates hedged).
  - **Respect operator decisions** (they override a critic): the share-and-follow line (2026-10-25), the pill
    captions (measured), no capsule, the diamond, review protection off, Approve one tap + Undo, Reject two taps.
  - **The operator is non-technical:** plain words in every card, button and report; lead with what to do.
  Every design brief carries the binding gates:
  - no slide chrome or fake UI;
  - no direction cues;
  - no engagement bait as Meta defines it. The ONE share-and-follow line is the operator's 2026-10-25 decision and
    stays;
  - figures from the verified fact sheet;
  - `src/safe_zones.py`;
  - credits;
  - privacy;
  - no emoji in art.
- **Git:** CRLF: write files with LF (bytes or `newline="\n"`). Bash heredocs collapse backslashes: use the Edit
  tool for code containing them. Commit locally in groups, push with releases.
