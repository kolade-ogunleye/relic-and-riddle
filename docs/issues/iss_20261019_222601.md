## Verified resolution (2026-10-20 end-to-end review)
The earlier note above overstated the fix: its "auto-skip" for thin fact sheets could never fire (the
error was swallowed as a generic ValueError). The inaccurate facts came from evidence rules that let
weak sources through, now closed (commits bcc08d2, b6eb7c1, 9a8cd27 on the remediation branches):
- The UNESCO matcher used the first site within 60 km and missed "Turkey"/"Türkiye", so a wrong site
  (Gorgan -> Golestan Palace) entered as top-tier evidence. It now needs a distinctive-name match.
- Any doi.org/openalex.org link counted as a scholarly source (a trade-magazine piece ranked tier 1);
  OpenAlex now ranks only journal articles, and only on-topic ones.
- Dates bypassed the source rule; they now need a strong source or two independent sites.
- The automatic hedge invented an attribution ("researchers have estimated"); it is now neutral.
- The second fact check passed when the checker was unavailable; it now fails closed.
- Gemini "retrieved sources" included URLs the model wrote itself; only search results count now.
Sheets built under the old rules are rebuilt automatically (RULES_VERSION 2). A thin sheet now
really skips to the next topic.
