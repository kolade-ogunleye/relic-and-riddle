## User Critique
Is there a point in getting this notification each time I run the dashboard command: "Dashboard sent above."?

## Antigravity (AGY) Autonomous Diagnosis & Resolution
1. **Diagnosis**:
   - In `src/control.py`, when handling commands `/start`, `/dashboard`, `/dash`, the handler executed `send_message(dash_text, dash_buttons)` to send the full interactive cockpit card, but then returned `"Dashboard sent above."`.
   - In `src/telegram_bot.py`, the returned string was unconditionally passed to `self.notify(reply)`, causing Telegram to dispatch an unwanted second bubble saying `"Dashboard sent above."` immediately after the dashboard card.
   - Furthermore, when the `cdash` inline button was clicked, `self.edit_message_text(msg_id, reply)` was being called with `reply = "Dashboard sent above."`, overwriting the cockpit card with that message.
2. **Resolution**:
   - In `src/control.py`:
     ```python
     if command in ("start", "dashboard", "dash"):
         dash_text, dash_buttons = dashboard_text_and_buttons(db, next_run(), assets_dir=assets_dir)
         if send_message:
             send_message(dash_text, dash_buttons)
             return ""
         return dash_text
     if command == "cdash":
         dash_text, _ = dashboard_text_and_buttons(db, next_run(), assets_dir=assets_dir)
         return dash_text
     ```
   - In `src/telegram_bot.py`:
     - Wrapped command notification with `if reply: self.notify(reply, record_alert=False)` so empty replies do not generate empty or redundant Telegram bubbles.
     - Upgraded the `cdash` callback query handler to update the existing message in-place with both `dash_text` and `dash_buttons`:
       ```python
       if action == "cdash" and msg_id:
           dash_text, dash_buttons = dashboard_text_and_buttons(self.db, next_fn(), assets_dir=ASSETS_DIR)
           self.edit_message_text(msg_id, dash_text, buttons=dash_buttons)
       ```
   - Added unit test `test_dashboard_command_no_redundant_sent_above_message` in `tests/test_control.py`.
3. **Verification**:
   - All 41 unit tests in `tests/test_control.py` pass cleanly.
