Attached screenshot shows an authorized user using Telegram's native swipe-to-reply feature on an `/ask` response with the query:
*"Can we get to the bottom of why Veo ran when Kling had credit in the last pipeline run?"*
The bot previously did not respond to native message replies because messages without a leading `/` slash were dropped.

## Antigravity (AGY) Autonomous Diagnosis & Resolution
1. **Diagnosis**:
   - **Native Telegram Swipe-to-Reply**:
     - In `src/telegram_bot.py`, `poll_once()` enforced `if not text.startswith("/"): continue`.
     - When the operator used Telegram's native reply feature to ask follow-up questions to an `/ask` intelligence card, the message did not start with a slash and was silently discarded.
   - **Evidence & Issue Path Resolution**:
     - Evidence files uploaded via `/issue` were saved using relative path `Path("docs/issues/evidence")`, which saved files to the outer execution directory rather than the project workspace root.
   - **Kling Failover to Veo Telemetry**:
     - In `src/motion.py`, when Kling is called and fails (or hits a transient timeout/credit issue), the cascade caught the error and seamlessly fell over to Veo so production never halted. However, the exact failure reason was only logged to `log.warning` and not stored in `motion.last_fallback_reason` or `script_metadata.json`, leaving operators without immediate visibility into why Veo ran.
2. **Resolution**:
   - **Native Swipe-to-Reply Support (`src/telegram_bot.py`)**:
     - Upgraded message polling to detect `reply_to_message`.
     - When an authorized operator replies to any bot message (including `/ask`, `/dashboard`, or alerts) without typing a slash, the bot automatically intercepts it as a contextual inquiry:
       - Extracts the parent message's context.
       - Dispatches it to `probe_system(f"{text}\n\n[Context from replied message]: {parent_text}")`.
       - Triggers `sendChatAction("typing")` and responds directly to the user.
   - **Deterministic Fallback Recording (`src/motion.py`)**:
     - Added global tracking for `last_fallback_reason` in `src/motion.py`.
     - When Kling fails, times out, or encounters a budget limit, the failure reason is preserved and surfaced via `/ask` and `telemetry["motion_fallback_reason"]`.
   - **Project-Root Evidence Path**:
     - Anchored `evidence_dir` and `issues_dir` to `Path(__file__).resolve().parent.parent` so issue records and screenshots always land cleanly in `relic-and-riddle/docs/issues/evidence/`.
3. **Verification**:
   - Added unit test `test_native_telegram_reply_to_message_routing` in `tests/test_control.py` verifying swipe-to-reply routing.
   - Added unit test `test_motion_fallback_tracking` in `tests/test_control.py` verifying failover tracking.
   - All 82 tests in the test suite pass with 100% success rate.
