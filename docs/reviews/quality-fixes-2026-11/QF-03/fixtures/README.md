# Photo benchmark fixtures

These are resized/recompressed copies of the same two photographs used by the
predecessor's Wieliczka cross-check. Long edge is at most 1,200 px, ffmpeg JPEG
quality 8, metadata removed. Each JPEG is under 300 KB. Both before and after
must use these exact copies; old full-resolution bitrate numbers are historical
cross-checks, not the new acceptance denominator.

- `salt.jpg`: [Rock salt. Wieliczka, Poland-8851.jpg](https://commons.wikimedia.org/wiki/File:Rock_salt._Wieliczka,_Poland-8851.jpg).

  This resized copy is distributed under CC BY-SA 4.0.
